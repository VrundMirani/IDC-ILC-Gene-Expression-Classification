# Dataset

The datasets used in this study are not included in this repository.

The research workflow uses breast cancer molecular and clinical data for classification of infiltrating ductal carcinoma (IDC) and infiltrating lobular carcinoma (ILC).

The primary analysis dataset contains gene-expression and related molecular/clinical variables, including the histological.type target variable.

Researchers attempting to reproduce the analysis should obtain the dataset from its authorized source and comply with all applicable licensing, attribution, and data-use requirements.

The notebooks document the analysis workflow and expected data structure.
